# LiarVR Image Placement Guide

Keep these filenames unchanged so the README images continue to render.

| Filename | Where it appears | What to place here |
|---|---|---|
| `hero.png` | Top of README, under the video link | Best frame from the demo video: VR tavern table, visible cards, play box, and ideally both players. Current version uses the existing homepage thumbnail as a placeholder. |
| `game_logic.png` | Game Rules and Flow | Flowchart showing the two play modes: normal turn-taking and challenge resolution. |
| `tavern_scene.png` | Optional future image | Add a clean scene screenshot showing the tavern, table, cards, and play box. |
| `tutorial_ui.png` | World-Space Player Guidance | World-space tutorial panel or turn/challenge guidance UI. |
| `body_tracking.png` | Embodied Avatar and Body Tracking | Robot avatar, Meta Movement SDK body tracking, or character scale setup. |
| `card_interaction.png` | Card Interaction Debugging | Card grabbing, card prefab, or debugging evidence for Photon/physics conflict. |
| `endgame_effects.png` | End-Game Feedback | Victory fire effect and defeat smoke effect. |
| `evaluation.png` | Evaluation and Future Work | Presence questionnaire or dimension-score chart from the report. |

Tip: if you replace the current report-page screenshots with cropped figures, keep the same filenames and commit again.
